本机运行与分析服务

设置

运行环境、媒体处理和模型凭据集中管理。

运行环境

选择 OpenCLI 可执行文件和浏览器 Profile；留空时使用当前 PATH 与默认 Profile。

Windows 上优先将 pnpm/npm 的路径放在 WindowsApps 前；也可以在此指定启动文件。
LLM API 密钥不会在此页面输入或写入 JSON。原始媒体保存在本机 output/media；启用分析时，媒体内容和笔记上下文会通过 HTTPS 发至所配置的 LLM 服务。

项目依赖

更新 requirements.txt 中的 Python 依赖和通过 npm 或 pnpm 安装的 OpenCLI；Node.js 仅检查版本。更新后请重启 WebUI。

密钥保护与连接检查

密钥会在浏览器内加密后再提交；服务端只在内存中解密，并写入 Windows Credential Manager。

密钥不会以明文进入 WebUI HTTP 请求、配置 JSON 或日志。浏览器使用一次性 RSA-OAEP/AES-GCM 加密载荷；服务端私钥仅驻留进程内存。也可使用终端隐藏输入命令设置。
